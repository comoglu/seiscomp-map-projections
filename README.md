# seiscomp-map-projections

Extra map projections for the SeisComP GUI framework (`libseiscomp_gui`),
built as runtime-loadable plugins.

The first plugin, **`libmapazimuthal`**, adds three spherical **azimuthal
("globe")** projections — `Orthographic`, `Stereographic` and
`AzimuthalEquidistant` — an open alternative to the "Spherical" projection
in gempa's commercial `mapprojections` plugin.

See the `azimuthal-projections` branch / pull request for the
implementation, build and deployment instructions.
